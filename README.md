# 🥤 Slider de Refrigerantes
Um slider/carrossel interativo e estilizado feito com **HTML5, CSS3 e JavaScript puro (Vanilla JS)**. O projeto apresenta diferentes sabores de refrigerantes com transições animadas, alteração dinâmica do fundo usando variáveis CSS e navegação simplificada.

---

## 🚀 Funcionalidades

- **Navegação Interativa:** Botões de "Anterior" (`#prev`) e "Próximo" (`#next`) para alternar entre os itens.
- **Carrossel Infinito:** Ao chegar no último item, o slider retorna automaticamente para o primeiro (e vice-versa).
- **Cores Dinâmicas:** Cada slide define sua própria cor de fundo usando variáveis CSS em linha (`--background`).
- **Animações Fluidas:** Utilização de `@keyframes` em CSS para animações de entrada dos títulos e das imagens dos produtos ao mudar de slide.
- **Design Moderno:** Sobreposição de elementos em camadas (`z-index`) para criar efeito visual atraente.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica dos elementos do carrossel.
- **CSS3:** Estilização, animações (`@keyframes`), posicionamento absoluto e variáveis CSS.
- **JavaScript (ES6+):** Manipulação da DOM para alternar as classes ativas do slider.
